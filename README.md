 HR Recruitment Management Dashboard

 Project Overview
This project is an Excel-based HR Recruitment Management Dashboard designed to manage candidate information and monitor recruitment activities.

 Features
- Candidate information management
- Interview status tracking
- Application status tracking
- Dropdown menus using Data Validation
- Automatic candidate counting using Excel formulas
- Recruitment status chart
- Interview status chart
- HR dashboard for recruitment analysis

 Tools Used
- Microsoft Excel
- Excel Formulas (COUNTIF, COUNTA)
- Data Validation
- Charts and Data Visualization

 Dashboard Metrics
- Total Candidates
- Selected Candidates
- Rejected Candidates
- Shortlisted Candidates
- Under Review Candidates
- Pending Interviews
- Completed Interviews
- Scheduled Interviews

Learning Outcomes
- Understanding recruitment workflows
- Managing candidate records
- Using Excel formulas
- Creating recruitment reports
- Building an HR dashboard

Note
This project uses fictional sample candidate data for educational and portfolio purposes.
